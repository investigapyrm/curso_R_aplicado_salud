# Diccionario de datos

Dataset: `data/datasets/salud_muestra.csv`

Los datos son ficticios y se usan solo para práctica educativa.

| Variable | Tipo | Descripción |
| --- | --- | --- |
| id | entero | Identificador ficticio del registro |
| edad | entero | Edad en años |
| sexo | texto | F o M |
| peso_kg | numérico | Peso en kilogramos |
| talla_cm | numérico | Talla en centímetros |
| imc | numérico | Índice de masa corporal |
| presion_sistolica | numérico | Presión arterial sistólica |
| presion_diastolica | numérico | Presión arterial diastólica |
| glucosa_mg_dl | numérico | Glucosa en mg/dl |
| colesterol_mg_dl | numérico | Colesterol total en mg/dl |
| tabaquismo | texto | Si/No |
| actividad_fisica | texto | Alta, Media o Baja |
| diagnostico | texto | Clasificación ficticia de riesgo |
| seguimiento | texto | Recomendación ficticia de seguimiento |
