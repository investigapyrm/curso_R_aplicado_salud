# Manual de usuario

## Acceso

Abrir `index.html` o la URL de GitHub Pages. Usar las credenciales demo:

- Usuario: `estudiante`
- Contraseña: `r-salud`

## Recorrido recomendado

1. Ingresar al aula.
2. Abrir `Ruta del curso`.
3. Completar cada unidad en orden.
4. Marcar el checklist de materiales, actividad, tarea y quiz.
5. Usar el laboratorio R para copiar scripts base.
6. Publicar el informe final en RPubs.
7. Registrar el enlace en `Proyecto RPubs`.

## Progreso

El avance se guarda en el navegador. Si se borra el almacenamiento local, se pierde el progreso marcado.

## Instalación PWA

En navegadores compatibles aparecerá la opción de instalar el aula. El contenido principal queda cacheado para consulta posterior.
