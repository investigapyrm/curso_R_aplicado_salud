# Manual de usuario

## Acceso

Abrir `index.html` o la URL de GitHub Pages. Usar el acceso inicial reiniciado:

- Usuario: `admin`
- Contraseña: `123456`

Este acceso no depende del correo ni de recordatorios automáticos.

## Recorrido recomendado

1. Ingresar al aula.
2. Abrir `Ruta del curso`.
3. Completar cada unidad en orden; las unidades siguientes se desbloquean al completar la anterior.
4. Participar en el foro de cada subnivel.
5. Rendir cuestionarios y revisar retroalimentación.
6. Subir evidencias si corresponde: capturas, gráficos, scripts o reportes.
7. Usar el laboratorio R para copiar scripts base.
8. Publicar el informe final en RPubs.
9. Registrar el enlace en `Proyecto RPubs`.

## Progreso

El avance se guarda en el navegador y se intenta sincronizar con Google Sheets. Si no hay conexión, queda en la cola local y se puede enviar luego desde el panel de sincronización.

## Foros

Cada unidad propone preguntas por subnivel. Los aportes se registran en la hoja `FOROS` cuando el backend está disponible.

## Evidencias

Las evidencias se suben a Google Drive y quedan registradas en la hoja `EVIDENCIAS`. No subir datos personales reales ni imágenes clínicas identificables.

## Instalación PWA

En navegadores compatibles aparecerá la opción de instalar el aula. El contenido principal queda cacheado para consulta posterior.
