## Pregunta

¿Cómo varía la glucosa según diagnóstico en la base de práctica?

## Preparación

```{r}
library(tidyverse)
salud <- read.csv("data/salud_muestra.csv")
```

## Resultados

```{r}
salud |>
  group_by(diagnostico) |>
  summarise(n = n(), glucosa_media = mean(glucosa_mg_dl))
```
