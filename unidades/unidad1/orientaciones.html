Unidad 1: Instalación de R, RStudio y primeros pasos

La primera unidad prepara el entorno de trabajo. El objetivo no es memorizar comandos, sino crear una base ordenada para que cada análisis pueda repetirse.

Antes de empezar

  • Descargar R desde CRAN.
  • Instalar RStudio Desktop desde Posit.
  • Crear una carpeta del curso con subcarpetas `data`, `scripts`, `figuras` y `reportes`.
  • Guardar cada bloque de trabajo en un script `.R`.

Producto de la unidad

Un script `01_instalacion.R` que cargue paquetes, ejecute cálculos simples y muestre la información de sesión.
