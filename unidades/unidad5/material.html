Regresión logística

salud <- salud |>
  mutate(diabetes_probable = diagnostico == "Diabetes probable")

modelo_logistico <- glm(
  diabetes_probable ~ edad + imc + tabaquismo,
  data = salud,
  family = binomial
)

summary(modelo_logistico)
broom::tidy(modelo_logistico, exponentiate = TRUE, conf.int = TRUE)

Los odds ratio mayores a 1 sugieren aumento de odds; menores a 1 sugieren reducción, siempre bajo las limitaciones del modelo.
