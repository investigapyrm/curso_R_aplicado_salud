Modelos sencillos en datos de salud

Lectura interna del aula para trabajar regresion lineal, regresion logistica, OR, R2 y limitaciones. Este material reemplaza el documento externo embebido: se lee directamente dentro de la secuencia del curso.

Objetivo de la unidad

Ajustar modelos simples con datos de salud y comunicar resultados sin convertir una asociacion estadistica en una conclusion causal exagerada.

Regresion lineal Para desenlaces continuos: por ejemplo glucosa, IMC, presion arterial o dias de internacion.
Regresion logistica Para desenlaces binarios: por ejemplo consultar/no consultar, cobertura si/no o evento presente/ausente.
Lectura clinica Reportar estimado, intervalo de confianza, contexto y limitaciones.

Ensayos en R

1. Modelo lineal: desenlace continuo

salud <- read.csv("/data/salud_muestra.csv")
modelo_lineal <- lm(glucosa_mg_dl ~ imc + edad, data = salud)
summary(modelo_lineal)
Lectura esperada: una pendiente indica el cambio promedio del desenlace por una unidad de la variable explicativa, manteniendo constantes las demas variables del modelo.

2. Modelo logistico: desenlace si/no

salud$diabetes_probable <- salud$diagnostico == "Diabetes probable"
modelo_log <- glm(diabetes_probable ~ edad + imc + tabaquismo,
                  data = salud, family = binomial)
exp(coef(modelo_log))
Lectura esperada: exp(coef) devuelve odds ratios. Un OR no es una probabilidad; compara odds entre niveles o por unidad de cambio.

3. Intervalos y prudencia

confint(modelo_log)
AIC(modelo_log)
El intervalo de confianza muestra precision. El AIC ayuda a comparar modelos, pero no reemplaza criterio clinico ni diseno epidemiologico.

Como leer un modelo sin sobreinterpretar

  • Primero declarar el desenlace y su tipo: continuo o binario.
  • Luego nombrar predictores y ajuste: edad, IMC, sexo, area u otros.
  • Despues reportar estimado e IC95%, no solo p-valor.
  • Finalmente escribir una frase clinica prudente y una limitacion.

Ejemplo: "En este conjunto de practica, mayor IMC se asocio con mayor glucosa promedio, ajustando por edad. El resultado es exploratorio y no permite concluir causalidad".

Limitaciones minimas a declarar

  • Un modelo no corrige sesgos de captura o medicion.
  • La asociacion puede depender de confusores no medidos.
  • La significancia estadistica no garantiza relevancia clinica.
  • La prediccion requiere validacion; ajustar un modelo no basta.
